---
title: "Dashboard UI"
description: "Manage mcp servers through the mcpjungle Dashboard UI"
---

Mcpjungle lets you manage MCP servers, tools, tool groups, prompts, resources, and skills through a Web UI.

Once your server is running, open the dashboard in your browser at [http://localhost:8080/](http://localhost:8080/) or whatever port the server process is listening on. Use **+ Add Server**, **+ Add Tool Group**, and **+ Add Skill** to operate the gateway — you do not need a separate management CLI.

![MCPJungle dashboard UI](/images/dashboard-ui.png)

The Dashboard is currently only supported when running mcpjungle in [development mode](/core-concepts#development-mode-vs-enterprise-mode).

<Note>
  Dashboard is currently a Beta feature. Please report any issues or feedback you have.
</Note>
