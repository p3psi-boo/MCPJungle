---
title: "Manage Resources"
description: "Inspect MCP resources exposed by servers registered in Mcpjungle."
---

When you register an MCP server, Mcpjungle also registers any resources exposed by that server.

Each resource receives a URI that is unique across Mcpjungle. See [Core concepts](/core-concepts#resources) for the resource URI model and how Mcpjungle keeps resources from different servers distinct.

## Inspect resources

Open the **Resources** page in the dashboard to see every registered resource, its server, MIME type, and URI.

MCP clients read resource contents through the gateway. Copy a resource URI from the dashboard if you need to pass it to a client.
